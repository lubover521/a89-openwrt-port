# E5 TF 卡刷入包（2026-10-10）

面向荣悦 E5 的本地增量构建，基于已合并的 `main`。沿用实机验证过的
`6.18.54-e5-mobile4-g020b970e351e-dirty` 内核及完整匹配模块，重新组装
启动镜像和 2 GiB ext4 系统镜像。系统基础包复用本机离线 E5 根目录中的
OpenWrt 25.12.5 ARM64/musl 二进制；这不是从零编译所有第三方软件包。

包含 Aurora 看板和移动屏幕、双卡控制/流量/短信、CPU 设置、OTG 修复、
userdata 挂载失败恢复、充电插拔亮屏、主页六项确认，以及 r13 通话修复。
不采用 T551M 的设备树、充电驱动或固定 152 网络模式。

打包根目录重新生成网络、账号、屏幕和插件配置，去掉主机密钥、TLS 证书、
随机种子、机器标识、短信/通讯录/流量记录、蓝牙配对、厂商固件和 Android
子目录。安装器从目标 E5 的 Android 收集其自身固件。
默认只保留 Docker 所需内核支持与适配工具，不预装 Docker、containerd、runc
及其压测工具；需要时按 [容器说明](CONTAINERS.zh-CN.md) 自行安装。
首次安装按安装器配置默认启动 OpenWrt，保留 Android A 槽。

打包时修复了更新迁移中的问题：原 `keep_config` 会用旧电话插件覆盖镜像内
的新程序。现在保留包内电话程序，同时保留通讯录、密码、系统设置和其他
应用；不含电话插件的旧式镜像仍按原逻辑保留已安装电话插件。
`openwrt/tests/image-keep-config.py` 使用真实迁移函数测试这两种情况。

安装方式：

- 首次安装：E5 在已 root 的 Android 下，通过 USB 运行 `flash.cmd`；默认
  安装到 TF 卡，会清空卡。建议 8 GB 或更大，首次安装至少 4 GB。
- 更新现有 TF 系统：在 OpenWrt 下运行 `flash.cmd --update`，保留设置；
  卡上需要另一个约 2 GiB 系统分区的空间。
- 默认管理地址 `192.168.9.1`，账号/初始密码 `root` / `root`。

交付目录附 `BUILD.json`、逐文件 `SHA256SUMS` 和压缩包外部校验文件。
验证包括 ARM64 程序加载/首次网络配置、匹配内核模块清单、TF/F2FS 策略、
隐私文件检查、ext4 只读检查及 ZIP CRC/逐文件哈希核验。
本次只制作包，没有对设备或实体 TF 卡执行安装；完整首次刷入仍待实物验证。

2026-10-11 更正：首个 TF 包复用了容器验证环境，误带 Docker 运行程序。
修正版通过 APK 包管理器卸载 Docker 及仅被它依赖的用户态组件，同步包数据库，
清除预设 Docker 服务、数据目录和防火墙项，保留匹配的全部内核模块。
E5 构建示例显式使用 `E5_DOCKER=0`；原构建脚本的默认值仍为 `0`。
