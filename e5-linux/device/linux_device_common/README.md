# linux_device_common

Shared linux adaptations and runtime assets.

Used by [sprd-linux-devs/e5-linux](https://github.com/sprd-linux-devs/e5-linux) as a pinned Git submodule at `device/linux_device_common`.

See `profile.json` for identity and the parent `device/manifest.json` for overlay order.
Device firmware, calibration, credentials and generated images belong in the parent `work/` and `out/` directories.
